Справка

Назначение программы

Программа анализирует графы по матрице инцидентности: проверяет на петли, кратные рёбра, вычисляет степени вершин, строит матрицу смежности.

Математическая модель

  • Матрица инцидентности — таблица размером E×V (рёбра × вершины), где:
    • 1 — вершина инцидентна ребру
    • 0 — вершина не инцидентна ребру
    • В строке: 2 единицы = обычное ребро, 1 единица = петля
  • Степень вершины — количество инцидентных рёбер (петля учитывается дважды)
  • Матрица смежности — квадратная матрица V×V, где a_ij = количество рёбер между v_i и v_j

Элементы интерфейса

  • Вершины / Рёбра — поля для указания размеров матрицы (1–15)
  • Ячейки матрицы — ввод 0 или 1 (при фокусе очищаются)
  • Кнопки ↑↓ — пошаговое изменение значения ячейки
  • «Рассчитать» — запуск алгоритма выбранного модуля
  • «Очистить матрицу» — сброс всех значений на 0
  • Навигация — переключение между модулями в верхней панели

Описание модулей

МодульНазначение
ПсевдографПроверяет наличие петель в графе
ПетлиНаходит все вершины с петлями
СтепениВычисляет степени всех вершин
РегулярностьПроверяет, одинаковы ли степени всех вершин
СмежностьСтроит матрицу смежности по матрице инцидентности
МультиграфПроверяет наличие кратных рёбер между вершинами

Ограничения

  • Количество вершин и рёбер: от 1 до 15
  • Значения матрицы: только 0 или 1
  • В каждой строке матрицы: 1 или 2 единицы (иначе — ошибка)
